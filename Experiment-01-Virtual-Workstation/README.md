# Virtual Workstation

## AIM

To install VirtualBox/VMware/Equivalent open source cloud Workstation with different flavours of Linux or Windows OS on top of Windows 8 and above.

## ALGORITHM

1. Go to the VirtualBox website and download the Windows host installer.
2. Open the downloaded VirtualBox EXE file.
3. Click Next in the Welcome window.
4. Choose the installation folder and required features.
5. Accept installation of the Oracle VirtualBox interfaces.
6. Click Install and wait for installation to complete.
7. Click Finish to open VirtualBox.
8. Click New and enter the virtual machine name.
9. Select the installation path and ISO image.
10. Select the appropriate OS Type and Version/Architecture.
11. Allocate Base Memory of 512 MB and 1 CPU.
12. Allocate a virtual hard disk of 2.00 GB.
13. Verify the VM configuration and click Finish.
14. Select the virtual operating system and click Start.
15. Follow the guest OS installation steps and verify the guest desktop.
