# Install Google App Engine and Create Hello World

## AIM

To Install Google App Engine. Create hello world app and other simple web applications using python/java.

## ALGORITHM

1. Install Google Plugin for Eclipse.
2. If required, obtain and extract the Google App Engine Java SDK.
3. In Eclipse, click the Google icon and select New Web Application Project.
4. Deselect Google Web Toolkit if required and configure the Google App Engine Java SDK.
5. Finish the project creation so that Eclipse generates the sample project.
6. Review the generated project structure containing source code, META-INF, WAR, WEB-INF, libraries and classes.
7. Configure `appengine-web.xml`.
8. Run the project locally using Run As > Web Application.
9. Verify that the development server runs at `http://localhost:8888/`.
10. Access the Hello World application in the browser.
11. Register an App Engine application ID when deployment is required.
12. Add the application ID to `appengine-web.xml`.
13. Use the GAE deploy button and sign in with the Google account.
14. Deploy and verify the application URL.
