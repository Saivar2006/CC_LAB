# Ex.No: 05-CloudSim

# Simulate a Cloud Scenario Using CloudSim

## AIM

To Simulate a cloud scenario using CloudSim and run a scheduling algorithm that is not present in CloudSim.

## ALGORITHM

1. Download Eclipse for Windows 64-bit.
2. Download CloudSim 3.0.3 from the CloudSim GitHub release.
3. Download Apache Commons Math 3.6.1.
4. Extract Eclipse, CloudSim and Apache Commons Math.
5. Open Eclipse.exe.
6. Select File > New > Project.
7. Select Java Project.
8. Enter the project name as `CloudSim`.
9. Unselect Use default location.
10. Browse to the extracted CloudSim project source.
11. Continue until the project folders such as bin, docs and examples are visible.
12. Open the Libraries tab.
13. Use Add External JARs if commons-math3-3.x.jar is not already listed.
14. Select the Commons Math JAR and click Open.
15. Ensure the external JAR appears in the project library list and click Finish.
16. Allow Eclipse to build the project.
17. Open the examples package `org.cloudbus.cloudsim.examples`.
18. Open `CloudsimExample1.java`.
19. Run the program using Run or Ctrl+F11.
20. Verify the CloudSim console output.
